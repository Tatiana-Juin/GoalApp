# GoalApp

## Présentation
Cette application à pour objectifs de suivre l'abancer de ces objectifs par rapport à des sous objectifs que tu va determiner

## Générer un APK Android

Le workflow GitHub Actions génère automatiquement un APK de test à chaque push sur `main`. Tu peux aussi le lancer manuellement depuis l'onglet **Actions** du dépôt.

Après la réussite du workflow, télécharge `GoalApp-debug-apk` dans la section **Artifacts** de l'exécution. L'APK est un build debug installable pour tester l'application ; ce n'est pas un build de publication pour le Play Store.
