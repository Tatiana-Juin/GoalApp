# 🎯 GoalApp

GoalApp est une application mobile qui permet suivre l'avancer de ses objectifs.

L'objectif est d'aider les utilisateurs à avancer progressivement dans leurs projets en les divisant en sous-objectifs plus faciles à réaliser. Chaque objectif dispose d'un suivi de progression afin de visualiser son avancement.

## ✨ Fonctionnalités

L'application permet actuellement de :

### Objectifs
- **Ajouter** un nouvel objectif.
- **Modifier** un objectif existant.
- **Supprimer** un objectif.

### Sous-objectifs
- **Ajouter** des sous-objectifs pour décomposer un objectif en plusieurs étapes.
- **Modifier** un sous-objectif existant.
- **Supprimer** un sous-objectif.

### Suivi de progression
- Visualiser la progression de ses objectifs grâce à une barre de progression.
- Consulter les sous-objectifs associés à un objectif pour suivre les différentes étapes de réalisation.

## 🛠️ Technologies utilisées

Le projet utilise les technologies suivantes :

- **React Native** : création de l'application mobile.
- **TypeScript** : typage du code et amélioration de sa maintenabilité.
- **Expo** : environnement de développement et outils facilitant la création de l'application.
- **Expo Router** : gestion de la navigation entre les écrans.
- **Node.js** : environnement nécessaire pour exécuter les outils de développement et les commandes du projet.
- **Git** : gestion des versions et suivi des modifications du code.

## 📋 Prérequis

Avant de commencer, assurez-vous d'avoir installé :

- [Node.js](https://nodejs.org/) (version LTS recommandée).
- [Git](https://git-scm.com/).
- Un éditeur de code, comme [Visual Studio Code](https://code.visualstudio.com/).
- [Expo Go](https://expo.dev/go) sur votre téléphone, ou un émulateur Android configuré.

Pour vérifier les installations, ouvrez un terminal et exécutez :

```bash
node -v
npm -v
git --version
```

## 🚀 Installation du projet

### 1. Cloner le dépôt Git

Dans un terminal, exécutez la commande suivante :

```bash
git clone https://github.com/Tatiana-Juin/GoalApp.git
```

### 2. Accéder au dossier du projet

```bash
cd GoalApp
```

### 3. Installer les dépendances

Pour installer toutes les dépendances nécessaires au fonctionnement du projet, exécutez :

```bash
npm install
```

Cette commande installe les packages déclarés dans le fichier `package.json`.

## ▶️ Lancer le projet

Une fois les dépendances installées, démarrez le serveur de développement avec :

```bash
npx run start
```

Expo affiche alors un QR code dans le terminal.

Vous pouvez ensuite :

- Scanner le QR code avec Expo Go pour ouvrir l'application sur votre téléphone.
- Appuyer sur `a` dans le terminal pour lancer l'application sur un émulateur Android configuré.
